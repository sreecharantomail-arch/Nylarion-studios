## ⚡ Tech Stack & Features

- **Frontend**: HTML5, Vanilla CSS3 (Custom Variables, Cyber Grid & Midnight Navy Design System)
- **3D Graphics**: Three.js (Un-tinted 1:1 sRGB color accuracy, real-time background cutout generator, interactive 3D floating emblem, and dynamic particle field)
- **Typography**: Google Fonts (*Orbitron*, *Rajdhani*, *Inter*)
